# MYFIN — സമ്പൂർണ്ണ മലയാളം ഫിനാൻസ് മാനേജ്മെന്റ് വെബ് ആപ്പ്

നിത്യജീവിതത്തിലെ വരവും ചെലവും എളുപ്പത്തിൽ രേഖപ്പെടുത്താനും, ദിവസേനയും ആഴ്ചയിലും മാസത്തിലും ഉള്ള കൃത്യമായ കണക്കുകളും ചാർട്ടുകളും ലഭ്യമാക്കുന്ന ഒരു സമ്പൂർണ്ണ **മലയാളം / English** ഓഫ്‌ലൈൻ-ഫസ്റ്റ് ഫിനാൻസ് മാനേജ്മെന്റ് വെബ് ആപ്പാണ് **MYFIN**.

## പ്രധാന സവിശേഷതകൾ (Features)

- **വരവും ചിലവും രേഖപ്പെടുത്തൽ**: തീയതി, ഫിനാൻസ് ഡിവിഷൻ, വിഭാഗം (ഭക്ഷണം, വാടക, യാത്ര, ശമ്പളം മുതലായവ), കുറിപ്പ് എന്നിവയോടെ എളുപ്പത്തിൽ ചേർക്കാം, തിരുത്താം, നീക്കം ചെയ്യാം.
- **Finance Division & Category Management**: വ്യക്തിഗതം, കുടുംബം, ബിസിനസ്സ്, സമ്പാദ്യം തുടങ്ങിയ ഡിവിഷനുകളും വിഭാഗങ്ങളും ഉപയോഗിക്കാം — കൂടാതെ **പുതിയ വിഭാഗങ്ങളും ഡിവിഷനുകളും നേരിട്ട് കൂട്ടിച്ചേർക്കാം**.
- **വിഭാഗങ്ങൾ ഒറ്റനോട്ടത്തിൽ (Unified Category View)**: വിഭാഗങ്ങൾ (Categories) ഓപ്ഷനിൽ ക്ലിക്ക് ചെയ്താൽ മൊത്തത്തിലുള്ള വരവ്, ചിലവ്, ബാലൻസ് എന്നിവയും ഓരോ വിഭാഗത്തിലെയും കണക്കുകളും ഒറ്റ രീതിയിൽ കാണാം.
- **വിശകലന റിപ്പോർട്ടുകൾ**: ഇന്ന് (Daily), ഈ ആഴ്ച (Weekly), ഈ മാസം (Monthly), മുഴുവനും (All), കസ്റ്റം തീയതി (Custom Date) എന്നിങ്ങനെ ഫിൽട്ടർ ചെയ്യാം.
- **ചാർട്ടുകൾ (Chart.js)**: വരവ്-ചിലവ് താരതമ്യം (Bar Chart), വിഭാഗം തിരിച്ചുള്ള ചെലവുകൾ (Doughnut Chart).
- **ഡൗൺലോഡ് & പ്രിന്റ്**: UTF-8 BOM **CSV**, മലയാളം Unicode സപ്പോർട്ടുള്ള **PDF** ഡൗൺലോഡ്, നേരിട്ടുള്ള **Print** സൗകര്യം.
- **ഓഫ്‌ലൈൻ സംഭരണം & PWA**: IndexedDB / localStorage + Service Worker വഴി ഫോണിലും കമ്പ്യൂട്ടറിലും പൂർണ്ണമായും ഓഫ്‌ലൈനായി ഉപയോഗിക്കാം. JSON Backup Export/Import സൗകര്യവും ഉൾപ്പെടുത്തിയിട്ടുണ്ട്.
- **Dark & Light Theme + മലയാളം / English**: തീമും ഭാഷയും ഒറ്റ ക്ലിക്കിൽ മാറ്റാം.
